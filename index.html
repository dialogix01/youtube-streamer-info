О приложении

«Эфир 24/7» — это самостоятельно развёрнутое (self-hosted) веб-приложение, которое запускает круглосуточную или по расписанию видеотрансляцию на YouTube из заранее загруженных видеофайлов. Приложение работает на собственном сервере владельца и управляется только им самим через закрытую панель с паролем.

Что умеет приложение:
  • Запускать и останавливать прямые трансляции на YouTube-канале владельца по расписанию
  • Создавать новую трансляцию через YouTube Data API, назначать её название, описание и настройки доступа
  • Отправлять видеопоток на уже существующую трансляцию по ключу RTMP
  • Показывать статус трансляции (идёт/остановлена), полученный через YouTube API

Приложение предназначено только для личного использования владельцем канала и не распространяется как публичный сервис. Оно не имеет собственных пользователей, кроме администратора, который его развернул.

Используемый доступ Google

Приложение запрашивает OAuth-доступ к Google-аккаунту владельца со scope:

https://www.googleapis.com/auth/youtube

Этот доступ используется исключительно для создания, запуска, остановки и обновления метаданных (название, описание, превью) прямых трансляций на собственном YouTube-канале владельца. Приложение не обращается к чужим каналам и не передаёт этот доступ третьим лицам.

Политика конфиденциальности

Дата последнего обновления: 3 ноября 2026

Какие данные используются

Приложение получает через YouTube Data API v3 доступ только к данным, необходимым для управления собственными трансляциями владельца аккаунта: информация о канале, созданные трансляции, их статус и метаданные (название, описание, превью, настройки доступа).

Как данные хранятся

OAuth-токены доступа (refresh token) хранятся в зашифрованном виде локально на сервере владельца приложения и не передаются никаким сторонним сервисам или третьим лицам. Доступ к серверу защищён паролем, известным только владельцу.

Как данные используются

Полученные данные используются исключительно для работы функций приложения: автоматического создания и ведения прямых трансляций на канале владельца. Данные не используются для рекламы, аналитики, обучения моделей или передачи третьим сторонам.

Удаление данных

Владелец может в любой момент отозвать доступ приложения через настройки безопасности своего Google-аккаунта , а также удалить локально сохранённые токены, остановив приложение и удалив папку с данными на сервере.

Передача третьим лицам

Приложение не продаёт, не передаёт и не раскрывает полученные от Google данные каким-либо третьим лицам или сервисам, за исключением прямого взаимодействия с API YouTube/Google, необходимого для работы функций, описанных выше.
